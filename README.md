# HVS Keebs

HVS Keebs is a React + TypeScript e-commerce application for laptops, accessories, services, cart, checkout, customer orders, and admin management.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Firebase Authentication
- Cloud Firestore

## Run Locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Configure Firebase values in `.env`.

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Type Check

```bash
npm run lint
```
